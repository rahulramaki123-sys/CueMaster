# 🎱 CueMaster

A modern **Snooker Club Management System** built with **React.js** and **Bootstrap 5**.

CueMaster helps snooker clubs efficiently manage tables, customers, live games, billing, and game history through a clean and responsive interface.

---

## ✨ Features

- 🎱 Live Table Management
- ⏱️ Real-Time Game Timer
- 💰 Automatic Billing
- 👥 Customer Management
- 📜 Game History
- 📊 Dashboard Statistics
- 📱 Responsive UI
- ⚡ Fast & Modern Interface

---

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/rahulramaki123-sys/CueMaster.git
```

Go into the project

```bash
cd CueMaster
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
